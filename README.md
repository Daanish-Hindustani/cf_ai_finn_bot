# 🤖 Chat Agent Starter Kit

![npm i agents command](./npm-agents-banner.svg)

A finacal Agent to help make the best finacla desisons.
## Features

- 💬 Interactive chat interface with AI
- 🛠️ Built-in tool system with human-in-the-loop confirmation
- 📅 Advanced task scheduling (one-time, delayed, and recurring via cron)
- 🌓 Dark/Light theme support
- ⚡️ Real-time streaming responses
- 🔄 State management and chat history
- 🎨 Modern, responsive UI

## Prerequisites

- Cloudflare account

## Quick Start

1. Create subdomain
2. npm install
3. Run locally:

```bash
npm start
```

Example query:
```
Describe common techniques for managing investment risk (diversification, rebalancing, dollar-cost averaging) and give example workflows a beginner could follow.
```
